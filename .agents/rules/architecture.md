# Frontend Architecture Guidelines

## Project Overview
This is the web dashboard for the tennis tracking ecosystem (consuming data generated by the Wear OS app and served via the Go backend).

### Core Tech Stack
- **Framework:** Vue 3 (v3.5.25+) using Composition API & `<script setup>`.
- **Build Tool & Dev Server:** Vite (v7.3.1).
- **Language:** TypeScript for static typing and maintainability.
- **Styling:** Tailwind CSS (v3.4.19) with official plugins:
  - `@tailwindcss/forms`
  - `@tailwindcss/typography`
  - `@tailwindcss/container-queries`
- **Routing:** Vue Router for SPA navigation.
- **Data Visualization:** Chart.js with the `vue-chartjs` wrapper for statistics rendering.
- **Tooling & Code Quality:**
  - PostCSS & Autoprefixer
  - ESLint
  - Vue-TSC (for type-checking in `.vue` files)

## Core Philosophy
We optimize for **feature independence** and **scalability**. The codebase is divided into Business Domains, which contain specific Features. Code sharing is strictly regulated to prevent the "spaghetti shared folder" anti-pattern.

## Directory Structure
```text
src/
├── app/                  # Application entry point (main.ts, router setup, global styles, Tailwind entry)
├── shared/               # GLOBAL shared code (Strictly business-agnostic)
│   ├── components/       # Dumb UI components (BaseButton, Modal, BaseChart)
│   ├── composables/      # Global Vue utilities
│   ├── services/         # Base HTTP client
│   └── utils/            # Generic helpers
│
└── domains/              # Business Contexts
    │
    ├── tennis-core/      # Domain: Match logic and tracking
    │   ├── _shared/      # Domain-specific shared code (e.g., Tennis Math utils, core Match types)
    │   ├── match-stats/  # Feature Module
    │   │   ├── components/ # Charts using vue-chartjs go here
    │   │   ├── composables/
    │   │   ├── services/   
    │   │   ├── types/      
    │   │   └── index.ts  # PUBLIC API for match-stats
    │   │
    │   └── players/      # Feature Module
    │       ├── components/
    │       ├── ...
    │       └── index.ts  # PUBLIC API for players
    │
    └── account/          # Domain: User management
        └── settings/     # Feature Module
```
